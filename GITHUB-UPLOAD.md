# AMQM GitHub Upload

This package is prepared so the contents of this folder can be uploaded directly
to the root of the school's GitHub repository.

Do not upload the parent `AMQM-2.0-GitHub-v27` folder as a nested folder.

After upload, verify that `index.html` is visible at the repository root.

For GitHub Pages, enable Pages from the repository's Settings > Pages and use
the branch/folder containing `index.html`.

For production, the final school deployment will use the school's custom domain
and production hosting, not GitHub Pages as the permanent hosting target.
